# Clearwave – Productivity Website

## About the Project

Clearwave is a modern productivity website designed to help teams organise their work, manage projects, track tasks, and improve communication in one place.

The website focuses on providing a clean and user-friendly experience that helps teams work more efficiently.

## Live Website

[View Clearwave Website](https://effulgent-cajeta-5cfe54.netlify.app/)

## Features

- Modern and responsive website design
- Productivity dashboard showcase
- Mobile application showcase
- Platform features section
- Pricing plans
- Customer testimonials
- Integration showcase
- Frequently Asked Questions (FAQ)
- Why Choose Clearwave section

## Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and layout
- JavaScript – Interactive elements and functionality
